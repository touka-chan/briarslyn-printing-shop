  1. Hanapin ang labels sa ESP32 board (naka-print sa PCB): 3V3, GND, at D5 / D18 / D19 / D23 / D27. Ang "Dxx" ay pareho lang ng "GPIO xx" (D18 = GPIO 18).
  2. Kabitin ang 7 wires base sa table. Female-female jumper wires ang kailangan. Double-check ang 3V3 — hindi 5V/VIN.
  3. Iwanang blangko ang IRQ (walang wire).
  4. Isaksak ang USB cable (data cable, hindi charge-only) sa PC. Dapat may lalabas na COM port.
  5. Arduino IDE → Tools → Board: "ESP32 Dev Module" → tamang Port (COMx) → Upload.
  6. Buksan ang Serial Monitor @ 115200: dapat RC522 version 0x91/0x92 → WiFi IP → ping {"ok":true}.
  7. I-tap ang card/sticker → lalabas ang UID sa serial (e.g. 04A3B2C1).
Kung ayaw gumana: (1) "RC522 not detected" → loose wire, maling pin, o naikabit sa 5V. (2) Walang COM port → kulang ang USB driver (CP210x o CH340 — hanapin sa Device Manager). (3) WiFi fail → 5GHz ang network mo; 2.4GHz lang ang ESP32. (4) Kung loose ang header pins ng RC522 → kailangan i-solder ang 8-pin header.
